# Hero 3D · oficina miniatura

La portada monta una escena Three.js independiente de la autenticación y de las rutas privadas. La planta mide aproximadamente 15,5 × 10,2 unidades y contiene exactamente cinco figuras, cinco estaciones, una mesa de reunión, café, lounge, jardineras y un televisor con datos SG-SST demostrativos.

La cámara ortográfica usa una vista más frontal en móviles para mantener visible la oficina completa. El arrastre horizontal permite ajustar suavemente el ángulo. La animación dura 120 segundos: Zeus y Hera conversan, Jesús y Cristina se reúnen, y Apolo toma café. Todas las figuras regresan a sus escritorios. Con movimiento reducido, la escena queda estática.
