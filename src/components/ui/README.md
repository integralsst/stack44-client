# Controles visuales compartidos

Esta carpeta contiene únicamente controles reutilizados por más de una pantalla.

- `AppButton`: botón con variantes y estado de carga sin saltos de ancho.
- `AppIconButton`: botón compacto para acciones representadas por iconos.
- `AppSelect`: selector con flecha e icono opcional correctamente alineados.
- `AppModal`: contenedor modal común.

Los componentes específicos de evaluación permanecen dentro de `features/evaluacion`.
